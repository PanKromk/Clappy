# Sounds

Just drop files here - the game auto-detects them.

## Music
- `music_knights.mp3` (or `.wav` / `.ogg`) - Knights of Cydonia
- `music_friends.mp3` (or `.wav` / `.ogg`) - I'll Be There For You

If present, replaces the built-in MIDI synthesizer. Remove files to go back to MIDI.

## Clap sound
- `clap.mp3` (or `.wav` / `.ogg`)

If present, replaces the default synthesized clap. Remove file to go back to synth.
