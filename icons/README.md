# Custom Note Icons

Drop image files here to add them to the note pool alongside the default emoji.

## Supported formats
`.png` / `.jpg` / `.jpeg` / `.webp` / `.svg`

## Naming
Name files with a number: `0.png`, `1.jpg`, `2.webp`, etc.
Up to 30 icons are scanned (indices 0-29).

These are **added** to the existing emoji pool, not replaced.
